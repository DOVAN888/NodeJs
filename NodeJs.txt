// cau truc forer node js 
📁 node_modules          # Chứa thư viện cài bằng npm (không sửa)
📁 src/                 # Thư mục chính chứa mã nguồn

├─ 📁 config/            # File cấu hình chung (port, DB, biến môi trường)
├─ 📁 controllers/       # Xử lý logic các route (GET, POST...)
├─ 📁 public/            # Chứa file tĩnh như CSS, JS, ảnh
├─ 📁 route/             # Khai báo các đường dẫn (URL)
├─ 📁 services/          # Các hàm logic riêng (DB, API...)
├─ 📁 views/             # Chứa file .ejs (template giao diện)
├─ 📄 server.js          # Khởi động server chính

📄 .babelrc              # Cấu hình Babel để dùng ES6+ trong Node
📄 .env                  # Lưu biến môi trường (PORT, DB_URL...)
📄 .env.example          # File mẫu để clone về điền biến môi trường
📄 .gitignore            # Các file không đẩy lên Git
📄 NodeJs.txt            # Ghi chú cá nhân (tùy chọn)
📄 package.json          # Quản lý thư viện, script, thông tin dự án
📄 package-lock.json     # Ghi lại chính xác version thư viện

📋 Tổng hợp các Status API (HTTP Status Codes)

Mã	Ý nghĩa	Khi nào dùng
1xx - Informational (Thông báo)		
100	Continue	Client có thể tiếp tục gửi request
101	Switching Protocols	Server đồng ý đổi giao thức
102	Processing	Đang xử lý (WebDAV)

2xx - Success (Thành công)		
200	OK	Request thành công
201	Created	Tạo mới thành công (POST)
202	Accepted	Đã nhận request nhưng chưa xử lý xong
204	No Content	Thành công, không trả dữ liệu

3xx - Redirection (Chuyển hướng)		
301	Moved Permanently	Chuyển hẳn sang URL mới
302	Found	Chuyển tạm thời (redirect)
304	Not Modified	Client lấy dữ liệu cache (không thay đổi)

4xx - Client Error (Lỗi phía người dùng)		
400	Bad Request	Request sai (thiếu field, sai format)
401	Unauthorized	Không có quyền (chưa login hoặc token sai)
403	Forbidden	Đã login nhưng không đủ quyền
404	Not Found	URL hoặc tài nguyên không tồn tại
405	Method Not Allowed	Dùng sai method (ví dụ POST thay vì GET)
409	Conflict	Xung đột dữ liệu (ví dụ đăng ký email đã tồn tại)
422	Unprocessable Entity	Dữ liệu đúng format nhưng không hợp lệ (validate lỗi)

5xx - Server Error (Lỗi phía server)		
500	Internal Server Error	Lỗi trong server
502	Bad Gateway	Server backend chết, trả lỗi
503	Service Unavailable	Server quá tải hoặc bảo trì
504	Gateway Timeout	Server chờ backend nhưng hết thời gian
🎯 Cách nhớ cực nhanh:

Nhóm	Ý nghĩa
1xx	Server đang nói "chờ đi"
2xx	OK rồi, thành công! ✅
3xx	"Tới chỗ khác đi" (Redirect) 🔄
4xx	"Bạn sai rồi!" (Client error) ❌
5xx	"Tôi (server) lỗi rồi!" (Server error) 💥
📦 Một số status hay dùng nhất khi code API

Status	Dùng khi
200 OK	Gửi dữ liệu thành công (GET, POST thành công)
201 Created	Tạo mới (POST) thành công
204 No Content	Xoá xong nhưng không cần trả gì
400 Bad Request	Body gửi sai, thiếu trường
401 Unauthorized	Token hết hạn, login sai
403 Forbidden	User không đủ quyền
404 Not Found	Tài nguyên không tồn tại
409 Conflict	Đăng ký bị trùng
500 Internal Server Error	Lỗi server bất ngờ

mysql 
Mục	belongsTo	hasMany
Quan hệ	Nhiều bản ghi thuộc về 1 bản ghi khác	1 bản ghi có thể chứa nhiều bản ghi khác
Vị trí foreign key (FK)	FK nằm ở bảng hiện tại	FK nằm ở bảng khác
Truy vấn JOIN	Dùng để JOIN từ child → parent	Dùng để JOIN từ parent → children
Ví dụ	User.belongsTo(Role) → mỗi User có 1 role	Role.hasMany(User) → mỗi Role có nhiều user
